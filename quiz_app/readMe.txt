Démarrage du quiz : la première question s’affiche automatiquement.

Répondre : sélectionne une option et clique sur Valider.

Feedback : un message indique si ta réponse est correcte ou non.

Question suivante : clique sur le lien pour poursuivre.

Progression : une barre en haut montre l’avancée (ex. Question 3/5).

Résultat final : après la dernière question, tu accèdes à la page de résultats avec ton score.
